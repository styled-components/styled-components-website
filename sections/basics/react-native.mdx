## React Native

styled-components can be used with React Native in the same way and with the
same import. Try this example with [Snack by Expo](https://snack.expo.dev/@danielmschmidt/styled-components).

```tsx
import React from 'react'
import styled from 'styled-components/native'

const StyledView = styled.View`
  background-color: papayawhip;
`

const StyledText = styled.Text`
  color: #BF4F74;
`

const MyReactNativeComponent = () => (
  <StyledView>
    <StyledText>Hello World!</StyledText>
  </StyledView>
)
```

Complex styles that normally use arrays in React Native (such as `transform`)
and CSS shorthands (such as `margin`) work in tagged templates. In v7 this
support is built in; `css-to-react-native` is no longer a peer dependency.

> Note that the `flex` property works like CSS shorthand, and not the legacy
> `flex` property in React Native. Setting `flex: 1` sets `flexShrink`
> to `1` in addition to setting `flexGrow` to `1` and `flexBasis` to `0`.

Imagine how you'd write the property in React Native, guess how you'd transfer
it to CSS, and you're probably right:

```tsx
const RotatedBox = styled.View`
  transform: rotate(90deg);
  text-shadow-offset: 10px 5px;
  font-variant: small-caps;
  margin: 5px 7px 2px;
`
```

In v7, `keyframes`, media queries, container queries, and nested CSS work on
React Native. Native still has no document-level global stylesheet, so
`createGlobalStyle` is unavailable. See [React Native gets modern
CSS](/docs/v7#react-native-gets-modern-css) and the [compatibility
matrix](/docs/compatibility) for the supported surface and platform caveats.

### `toStyleSheet` API

As of v6.0.8, styled-components provides a `toStyleSheet` helper for React Native that converts a tagged template literal into a React Native StyleSheet-compatible object. This is useful when you need to work directly with React Native's `StyleSheet` API while still writing your styles in CSS syntax.

```tsx
import styled, { toStyleSheet } from 'styled-components/native'

const styles = toStyleSheet`
  background-color: papayawhip;
  color: #BF4F74;
`
// Returns a React Native StyleSheet-compatible object
```

### Simpler usage with the metro bundler

If you'd prefer to just import `styled-components` instead of `styled-components/native`, you can add a [`resolverMainFields` configuration](https://facebook.github.io/metro/docs/configuration#resolvermainfields) that includes `"react-native"`. This used to be supported in metro by default (and currently does work in haul) but appears to have been removed at some point.

For `react-native-web`, Webpack, Vite, and Metro web targets automatically select
the dedicated browser bridge in v7. If your bundler does not, import
`styled-components/native/web-bridge` directly.
